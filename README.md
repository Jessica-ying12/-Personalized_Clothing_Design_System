# Personalized Clothing Design System

个性化服装设计系统 - 毕业论文项目

## 项目结构

```
.
├── Personalized_Clothing_Design_System-app-flutter/   # Flutter 移动端应用
└── Personalized_Clothing_Design_System-backend-supabase/  # Supabase 后端服务
```

## 子项目说明

### Flutter App
移动端应用，基于 Flutter 开发。

```bash
cd Personalized_Clothing_Design_System-app-flutter
flutter pub get
flutter run
```

### Backend (Supabase)
后端服务，基于 Supabase 构建。

```bash
cd Personalized_Clothing_Design_System-backend-supabase
supabase start
```
