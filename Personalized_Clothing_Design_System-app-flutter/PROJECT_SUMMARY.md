## 🎯 用户流程

### 完整业务流程
```
注册/登录 → 选择平面图参数 → 生成平面图 → 选择立体图参数 
→ 生成立体图 → 查看/管理设计 → 下载/删除 → 查看历史记录
```

### 关键交互点
1. **登录页**：邮箱密码登录/注册
2. **平面图生成**：6 个参数选择 + 生成
3. **立体图生成**：5 个参数选择 + 生成
4. **仓库管理**：查看、下载、删除、重新生成
5. **历史记录**：查看所有记录、保存到仓库
6. **个人中心**：用户信息、退出登录、注销账号

