# 数据库操作 - 更新字段完整流程

## 元数据
- **分类**: 数据库操作
- **标签**: 更新字段, update, DAO, Service, 事务管理
- **适用场景**: 修改数据库某个字段值, 更新记录
- **相关文档**: DAO层职责, Service层职责, 事务处理最佳实践

## 快速回答

**问题**: 如何更新 MySQL 表中某个字段？

**答案**: 需要在三层分别编写代码 - DAO 层写数据库更新操作，Service 层处理业务逻辑和事务，Controller 层定义 API 接口。

---

## 完整步骤

### 第 1 步: DAO 层 - 数据库操作

📁 位置: `module_admin/dao/xxx_dao.py`

```python
from sqlalchemy import update
from sqlalchemy.ext.asyncio import AsyncSession
from datetime import datetime

@classmethod
async def update_user_status_dao(cls, db: AsyncSession, user_id: int, status: str):
    """
    更新用户状态数据库操作

    :param db: orm对象
    :param user_id: 用户ID
    :param status: 状态值
    :return: None
    """
    await db.execute(
        update(SysUser)
        .where(SysUser.user_id == user_id)
        .values(
            status=status,
            update_time=datetime.now()
        )
    )
```

**关键点**:
- 方法名以 `_dao` 结尾
- 使用 SQLAlchemy 的 `update()` 方法
- 第一个参数必须是 `AsyncSession`
- 方法必须是 `async`
- 同时更新 `update_time` 字段

---

### 第 2 步: Service 层 - 业务逻辑

📁 位置: `module_admin/service/xxx_service.py`

```python
from sqlalchemy.ext.asyncio import AsyncSession
from exceptions.exception import ServiceException
from module_admin.dao.user_dao import UserDao
from module_admin.entity.vo.common_vo import CrudResponseModel

@classmethod
async def update_user_status_service(cls, query_db: AsyncSession, user_id: int, status: str):
    """
    更新用户状态业务逻辑

    :param query_db: orm对象
    :param user_id: 用户ID
    :param status: 状态值
    :return: 更新结果
    """
    # 1. 业务校验
    if status not in ['0', '1']:
        raise ServiceException(message='状态值不合法')

    # 2. 权限校验（可选）
    user = await UserDao.get_user_by_id(query_db, user_id)
    if user.admin:
        raise ServiceException(message='不允许操作超级管理员')

    try:
        # 3. 调用 DAO 层
        await UserDao.update_user_status_dao(query_db, user_id, status)

        # 4. 提交事务（必须）
        await query_db.commit()

        return CrudResponseModel(is_success=True, message='更新成功')
    except Exception as e:
        # 5. 失败回滚（必须）
        await query_db.rollback()
        raise e
```

**关键点**:
- 方法名以 `_service` 结尾
- **必须**使用 `try-except` 包裹
- **必须**在成功后 `await query_db.commit()`
- **必须**在失败后 `await query_db.rollback()`
- 业务校验、权限校验在这一层

### 第 3 步: Controller 层 - API 接口

📁 位置: `module_admin/controller/xxx_controller.py`

```python
from fastapi import APIRouter, Depends, Request
from sqlalchemy.ext.asyncio import AsyncSession
from config.get_db import get_db
from module_admin.service.user_service import UserService
from utils.response_util import ResponseUtil

router = APIRouter()

@router.put("/user/status", dependencies=[Depends(CheckUserInterfaceAuth('system:user:edit'))])
async def update_user_status(
    request: Request,
    user_id: int,
    status: str,
    query_db: AsyncSession = Depends(get_db),
    current_user: CurrentUserModel = Depends(get_current_user)
):
    """
    更新用户状态接口

    :param user_id: 用户ID
    :param status: 状态值 (0正常 1停用)
    :return: 更新结果
    """
    result = await UserService.update_user_status_service(query_db, user_id, status)
    return ResponseUtil.success(model_content=result)
```

**关键点**:
- 使用 `Depends(get_db)` 获取数据库连接
- 使用 `Depends(CheckUserInterfaceAuth)` 进行权限验证
- 直接调用 Service 层方法
- 使用 `ResponseUtil.success()` 返回统一格式

## 完整示例：更新用户邮箱

### DAO 层
```python
@classmethod
async def update_user_email_dao(cls, db: AsyncSession, user_id: int, email: str):
    """更新用户邮箱"""
    await db.execute(
        update(SysUser)
        .where(SysUser.user_id == user_id)
        .values(email=email, update_time=datetime.now())
    )
```

### Service 层
```python
@classmethod
async def update_user_email_service(cls, query_db: AsyncSession, user_id: int, email: str):
    """更新用户邮箱业务逻辑"""
    # 校验邮箱唯一性
    if not await cls.check_email_unique_services(query_db, UserModel(userId=user_id, email=email)):
        raise ServiceException(message='邮箱已被使用')

    try:
        await UserDao.update_user_email_dao(query_db, user_id, email)
        await query_db.commit()
        return CrudResponseModel(is_success=True, message='邮箱更新成功')
    except Exception as e:
        await query_db.rollback()
        raise e
```

### Controller 层
```python
@router.put("/user/email")
async def update_user_email(
    user_id: int,
    email: str,
    query_db: AsyncSession = Depends(get_db)
):
    """更新用户邮箱接口"""
    result = await UserService.update_user_email_service(query_db, user_id, email)
    return ResponseUtil.success(model_content=result)
```

## 常见错误

❌ **错误 1**: 忘记提交事务
```python
await UserDao.update_user_dao(query_db, user)
# 缺少 await query_db.commit()  ❌
```

❌ **错误 2**: 没有异常处理
```python
await UserDao.update_user_dao(query_db, user)
await query_db.commit()
# 没有 try-except，失败时无法回滚  ❌
```

❌ **错误 3**: 在 DAO 层写业务逻辑
```python
# DAO 层不应该有这些判断 ❌
if user.admin:
    raise ServiceException(message='不允许操作管理员')
```
