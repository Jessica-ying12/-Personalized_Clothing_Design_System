# Hammer-Admin 项目规范知识库

## 📚 知识库说明

本知识库包含 Hammer-Admin 项目的开发规范、最佳实践和常见问题解答，设计用于向量检索（RAG）系统。

## 🗂️ 文档结构

### 1. 架构规范
- **01-架构规范-三层架构总览.md** - 项目整体架构说明

### 2. 数据库操作
- **02-数据库操作-更新字段完整流程.md** - 如何更新数据库字段的完整指南

### 3. SQL 管理
- **03-SQL管理-SQL文件存放位置.md** - SQL 脚本的组织和管理规范

### 4. 快速参考
- **04-快速参考-更新字段CheckList.md** - 更新字段操作的检查清单

### 5. 代码质量
- **05-代码质量-静态检查与Pre-commit配置.md** - 代码质量检查工具配置与使用

### 6. 实战流程
- **06-实战流程-国际化实现指南.md** - I18n、多语言支持、gettext、Babel 实现机制
- **07-实战流程-分页与多表查询指南.md** - PageUtil 分页工具、Join 查询、结果重组

## 🎯 使用方式

### 方式一：上传到 Dify 知识库

1. 将 `knowledge-base/` 目录下的所有 `.md` 文件上传到 Dify
2. Dify 会自动进行文档切片和向量化
3. 用户提问时，系统会自动检索相关文档

### 方式二：使用其他向量数据库

支持的向量数据库：
- Dify (推荐)
- Pinecone
- Weaviate
- Milvus
- Qdrant
- ChromaDB

## 🔍 检索优化建议

### 元数据字段
每个文档都包含以下元数据，便于精准检索：
- **分类** (category): 文档所属类别
- **标签** (tags): 关键词标签
- **适用场景** (use_cases): 适用的使用场景
- **相关文档** (related_docs): 相关联的其他文档

### 检索策略

**混合检索** (推荐):
- 向量检索权重: 0.7
- 关键词检索权重: 0.3
- 启用 Reranking

**配置示例**:
```json
{
  "search_method": "hybrid_search",
  "reranking_enable": true,
  "top_k": 3,
  "score_threshold": 0.7,
  "weights": {
    "vector_weight": 0.7,
    "keyword_weight": 0.3
  }
}
```
